# Prueba 03 del GPS 6M V2
Se realizará después de cerrar la `prueba 02` de GPS independiente.
Su objetivo será validar la velocidad del GPS con las IMU y estudiar la continuidad de la estimación cuando el GPS presente datos degradados.

## Contenido
Esta carpeta contendrá las pruebas, el análisis y el firmware de la prueba que incorporará las IMU junto con el GPS.
