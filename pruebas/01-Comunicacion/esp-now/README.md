# ESP-NOW

Esp-now fue el mejor de los 3 metodos debido a su inicilizacion rapida, La prueba fue igual que wifi, Una distancia de 50 metros Punto A Sala de proyectos 6j Punto B Entrada del cafeteria.

Para la pruba me fui caminando desde punto A a punto B. Y obtuvo resultados similares a wifi debido a que tambien empezo a perder paquetes cuando llegue al punto A
