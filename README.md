# Sistema de alerta de volcadura para pipas de bomberos

Esta carpeta concentra el avance técnico preparado y de los documentos existentes.


## Estructura del repositorio

La organizacion separa firmware, sensores, comunicaciones, pruebas, resultados y documentacion.

- firmware: codigo especifico de cada ESP32.
- sensores: implementacion y pruebas individuales de cada sensor.
- comunicaciones: pruebas de BLE, WiFi y ESP-NOW.
- pruebas: pruebas de cada placa y de integracion, también datos.
- docs: arquitectura, decisiones y entregas.
- configuracion-local: configuraciones que no deben subirse al repositorio.
