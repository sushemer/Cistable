# Cableado vigente de Peralta

recablear cabina. Usar la [tabla única y preparación S3](hardware-esp32s3.md).

se conserva como [historial ESP32 clásico](historial/cableado-cabina-esp32-peralta.md);
sus cinco compilaciones no acreditan S3.
